# Vi tích phân 1C

Bài giảng HTML và bài tập có hướng dẫn giải.

- Chuyên đề 01: Ôn tập và bổ sung kiến thức.
- Chuyên đề 02: Dãy số.

Website dự kiến: https://nhannguyenminh.github.io/vitichphan1c/

Mở `index.html` để truy cập các chuyên đề. Công thức sử dụng MathJax qua CDN và cần Internet. Bài giảng hỗ trợ phím mũi tên chuyển trang và phím F bật/tắt toàn màn hình.

Để xuất bản: Settings → Pages → Deploy from a branch → main → / (root) → Save.
